**text**　變化類型 參數用于指示生成的信息。 信息將從變化分析網格中進行提取。 對 CCDC 工具的輸出運行此工具時，可以從以下選項中選擇：
最新變化的時間 - 像素被標記為變化的最新日期和時間。
最早變化的時間 - 像素被標記為變化的最早日期和時間。
最大變化的時間 - 計算的變化為像素最顯著變化的日期和時間。

按起始值過濾 - 按起始值過濾，以僅在輸出中包含給定起始值的變化。
按結束值過濾 - 按結束值過濾，以僅在輸出中包含給定結束值的變化。

將此函數應用于 LandTrendr 工具的輸出時，您可以使用 分割日期 參數選擇提取標記變化開始還是變化結束的日期。 例如，要了解時間序列中的最新變化如何開始，請將 變化類型 設置為 最新變化的時間 ，并將 分割日期 設置為 時間段開頭 。
使用以下過濾參數可從變化分析網格中提取更具體的變化日期：
按年過濾 - 識別特定時間段內發生的變化，例如，持續五年的干旱中地表發生的變化。
按持續時間過濾 - 識別給定年份范圍內發生的變化，例如，在 1 或 2 年內發生的突然變化。 可使用公式 end year - start year +1 來計算持續時間。 將包含時間序列中的空白。
按量級過濾 - 識別給定量級的變化，例如，植被指數 NDVI 的較大變化。 量級是一個絕對值，因此最小值和最大值不能為負。 要指定方向變化，使用 變化方向 參數。

**source_en**　https://doc.esri.com/en/arcgis-pro/latest/help/analysis/raster-functions/detect-change-using-change-analysis-function.html

**parameter**　

**interface**　

**headers**　
- 參數
- 描述

**values**　
- 更改類型
- 指定要計算的變化信息。 最新變化的時間 - 每個像素將包含時間序列中該像素的最新變化的日期。 這是默認設置。 最早變化的時間 - 每個像素將包含時間序列中該像素的最早變化的日期。 最大變化的時間 - 每個像素將包含時間序列中該像素的最顯著變化的日期。 變化次數 - 每個像素都將包含時間序列中該像素發生變化的總次數。 最長變化的時間 - 每個像素都將包含時間序列中最長過渡段末尾的變化日期。 最短變化的時間 - 每個像素都將包含時間序列中最短過渡段末尾的變化日期。 最快變化的時間 - 每個像素都將包含發生速度最快的過渡末尾的變化日期。 最慢變化的時間 - 每個像素都將包含發生速度最慢的過渡末尾的變化日期。
