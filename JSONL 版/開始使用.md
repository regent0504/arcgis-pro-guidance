# ArcGIS Pro 繁體中文知識庫

在這個專案直接用中文提問即可。例如「地圖上的行政區怎麼依名稱標註？」或「幫我把目前專案的 A3 版面匯出成 PDF，存一份新檔」。代操作需要該次對話能存取 ArcGIS Pro 視窗或 ArcPy，以及指定的資料。

## 在其他模型使用

解壓後可選兩種格式。支援上傳文字檔的模型可從 Markdown 資料夾挑選章節分卷，每卷約 500 KB 以內。支援結構化檢索的系統可使用 JSONL。兩種格式包含同一批知識卡，擇一匯入即可。搜尋後保留卡片 id 和 source，方便引用及去重。模型的檔案數與上下文限制各不相同，可以先上傳工作需要的章節。

先前僅列於目錄的 18 頁現有繁中編寫卡，內容包括概念、既有結果判讀，以及適用的匯出步驟、輸出參數與授權。這一組採選摘編寫。可離線查閱地表、坡度、土地覆蓋資料型別，以及既有結果的時間檢視與匯出選項。卡片 coverage 記錄選摘範圍；遇到未列的參數或預設值，模型應明說缺少資料。

將 AGENTS.md 加為專案指示。將「ArcGIS-Pro-繁中知識卡.zip」解壓，選取所需章節的 JSONL 分卷匯入支援該格式的檢索系統，每行一張卡。索引 topic、english、chapter、section、text、steps、parameter、values 與 parameters，保留 id、kind、content_version、source 及 source_en。提問時帶出同頁用法與限制；單一參數卡可能無法涵蓋條件式必填或授權限制。SDK 成員索引分開匯入，供開發問題使用。

## 本機離線檢索

在專案資料夾執行。中文詞、英文工具名、ArcPy 參數名及錯誤碼均可使用。多個詞以空格分開，取同時匹配的卡片。

```powershell
python search_library.py 緩衝區 --kind 工具操作 --limit 3
python search_library.py Buffer buffer_distance_or_field --kind 參數
python search_library.py --page tool-reference/analysis/buffer.html --kind 版本參數表
python search_library.py 000732 --limit 3
python search_library.py --sdk EditOperation Abort
```

取得一張卡後，以 source_en 找同頁所有卡片。搜尋結果太少時，改用較短的關鍵詞或英文工具名。精準工具問題優先使用 --page，避免不同工具箱的同名工具混在一起。

## 來源、版本與收錄範圍

以 Esri 英文 latest 五大章節目錄界定母體。全站知識庫內的「收錄報告.json」列出實際頁數、卡數、各類型及僅有索引的頁面。「目錄.json」可用英文相對路徑反查主題層級。SDK 首頁另連獨立 .NET API 成員索引，可依成員或型別取得官方網址；成員詳細說明、程式多載、影片與站外教材採連線查閱。

主要卡片取自官方簡中 3.7 正文，轉為繁體並替換部分臺灣 GIS 用語。英文 3.8 新增頁面以本機模型翻譯並保留原文。具工具參數表的頁面另依英文 3.8 核對，記錄參數順序、識別字、型別、選填標示與英文說明。「工具操作」依各工具參數表編排，「有序步驟」來自原頁有序清單。「版本參數表」中的 optional_label 只反映原頁是否顯示 Optional；實際可用性與相依條件須讀該參數說明。

原有「知識卡.md」及 knowledge.jsonl 保留 37 個入門主題，方便快速閱讀。此專案的搜尋以擴充後的檢索資料庫為預設。
